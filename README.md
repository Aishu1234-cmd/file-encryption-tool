# 🔐 File Encryption & Decryption Tool

## 📌 Description
This project is a Python-based application that allows users to encrypt and decrypt files securely. It provides a simple and user-friendly graphical interface.

## 🚀 Features
- Encrypt files securely
- Decrypt files easily
- Simple GUI interface
- Fast and efficient

## 🛠️ Technologies Used
- Python
- Tkinter
- Cryptography (Fernet)

## ⚙️ Installation
1. Install Python
2. Install required libraries:
   pip install cryptography

## ▶️ How to Run
Run the following command:
python main.py
